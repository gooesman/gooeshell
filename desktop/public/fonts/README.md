# Bundled terminal fonts

These fonts are included unmodified. The application exposes their regular (400)
and bold (700) faces; the bundled DejaVu family also supplies italic faces.

- DejaVu Sans Mono 2.37: [official project](https://dejavu-fonts.github.io/),
  distributed under the accompanying `LICENSE-DejaVu.txt`. The same files and
  provenance are retained in `gooeshell/fonts/` in the source repository.
- JetBrains Mono 2.304: [official source](https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/ttf),
  release `v2.304` (`cd5227bd1f61dff3bbd6c814ceaf7ffd95e947d9`).
  See `LICENSE-JetBrainsMono.txt` (SIL Open Font License 1.1).
- IBM Plex Mono: [official source](https://github.com/IBM/plex/tree/bf260093582f04622aacc1e9f9ca604d7ccd0c42/packages/plex-mono/fonts/complete/ttf),
  revision `bf260093582f04622aacc1e9f9ca604d7ccd0c42`.
  See `LICENSE-IBMPlexMono.txt` (SIL Open Font License 1.1).

System fonts appear only when installed on the user's computer. Windows fonts
are not redistributed with the application.
