# gooeshell

Windows 优先的图形 SSH 终端与文件工作区，同时提供 macOS 和 Linux 构建。当前源码版本为 **1.0.0**，各平台可下载版本以发布页为准。默认黑色主题，也可切换白色；文件区默认收起，展开后在终端下方显示远程资源管理器，本地栏和传输队列默认折叠。

应用使用白鹅与橙色 `>_` 提示符图标，桌面程序、窗口及界面品牌保持一致。

当前图形版源码位于 **[desktop/](desktop/)**，采用 Electron、React、TypeScript、xterm.js WebGL 和 ssh2。SSH 与文件操作在后台 Worker 中执行，终端输出有流量控制。

0.4.2 优化大目录显示、终端输出解码及多标签事件分发；下载采用有界预读、按序落盘，保留完整校验与断点续传。性能对比、测试方法和适用边界见 [性能验证记录](PERFORMANCE.md)。

1.0.0 增加可选的命令状态与导航。在“连接设置 → 高级选项”开启“命令识别（Bash）”，下次连接启用；在“设置 → 字体与外观”选择右侧历史概览、左侧行标记或隐藏。绿色代表退出码 0，红色代表非零退出，灰色代表执行中或未知。点击标记定位，右键复制命令或输出，`Ctrl+↑/↓` 逐条跳转，快捷键可修改，隐藏标记后导航仍可用。

主动集成目前支持 Linux Bash，使用读取 `~/.bashrc` 的交互非登录会话，不读取登录 profile、不永久修改启动文件。默认关闭；已有不兼容钩子时保留原行为并提示。tmux/Vim 等备用屏幕内隐藏标记并透传导航键，暂不支持 tmux 面板级命令追踪；退出后恢复外层 Shell 导航。命令记录仅保存在当前终端内存，随滚动历史淘汰。历史禁用、过滤或没有提供完整命令时，仍可显示状态与位置，但不提供猜测的命令文本。

## 使用

从 [GitHub Releases](https://github.com/gooesman/gooeshell/releases) 下载对应平台的包，无需安装 Node.js。每个包名含版本、系统和处理器架构，发布页附 SHA-256 校验文件及构建提交信息。

| 平台 | 下载与打开方式 |
| --- | --- |
| Windows x64 | `win-x64.zip`，完整解压后打开 `gooeshell.exe`。 |
| Mac Apple Silicon（M 系列） | `mac-arm64.dmg`，拖入“应用程序”；也提供 ZIP。 |
| Mac Intel | `mac-x64.dmg`，拖入“应用程序”；也提供 ZIP。 |
| Linux x64 | Ubuntu / Debian 可安装 `linux-x64.deb`；另提供 `linux-x64.AppImage`，赋予执行权限后运行。 |

Mac 版本要求 macOS 13 或更新版本，与所用 [Electron 44 的系统要求](https://www.electronjs.org/zh/docs/latest/breaking-changes)一致。目前采用本地临时签名，尚未完成 Apple Developer ID 签名与公证；首次打开可能需要按 [Apple 的说明](https://support.apple.com/guide/mac-help/mh40616/mac)，在“系统设置 → 隐私与安全性”中允许打开。Linux 版本在 Ubuntu 24.04 构建与验证，其他发行版的完整桌面兼容性仍待实机验证。

开发构建可从 **Actions → gooeshell Desktop** 下载对应平台的构建产物。

点击“新建连接”，填写主机、端口、用户名，选择密码、私钥或 SSH Agent。默认首次连接会显示 SHA-256 指纹，可仅信任本次或保存。密码与私钥口令按所选方式保存，长期记住使用系统加密，不写入明文连接配置；取消“允许保存服务器指纹”后仍需确认，但不读取或保存旧指纹记录。

对于同一 IP 轮换设备的场景，右键侧栏服务器、最近连接或终端标签，打开 **连接设置 → 高级选项 → 此地址自动接受服务器指纹**。此选项按地址和端口单独保存，下次连接直接进行账号认证，不校验、不保存也不弹出指纹确认，不影响其他地址。关闭后恢复原来的指纹规则。此模式无法识别冒用该地址的服务器，适合确认可信的设备网络；同一次会话后续建立的文件连接仍须与首次连接的指纹一致。

## 图形界面

- **登录身份**：在顶部“设置 → 登录身份”预先保存身份名称、SSH 用户名与密码，连接及跳板机的身份验证区可分别选择。连接保存身份引用，更新身份后所有关联连接下次登录采用新信息，已有会话保留原登录用户。登录时可临时选择其他身份；仅勾选“设为此连接的默认登录身份”才更改默认。临时输入密码不会改写共享身份，勾选明确的更新选项并成功登录后才保存共享密码。有关联的身份需先解绑再删除。此版共享身份支持密码认证，独立连接仍支持私钥和 Agent。
- **推送 SSH 公钥**：在“连接设置 → 高级选项”打开，先保存当前连接设置，再选择已有密钥或生成 Ed25519。只将公钥安装到目标登录用户的 `~/.ssh/authorized_keys`，保留原条目和限制选项，重复密钥不重复追加。安装后使用选中的私钥独立验证，沿用跳板机路线；验证成功才可选择把此连接改为私钥登录，不改共享身份或其他连接。只选公钥可安装但不能验证或切换。生成的私钥留在本机，私钥口令按连接策略保存，原先不记住时仅在本次使用期间记住。
- **界面分区**：侧栏服务器右键仅保留“连接设置”；用户名位于身份验证区。收藏、分组、图标、编码、指纹、sudo、跳板机、公钥及连接管理统一置于默认收起的高级选项。顶部保留设置按钮，移除侧栏重复设置入口及顶部纯终端模式按钮，已有模式快捷键保持可用。“键盘与鼠标”统一设置快捷键、鼠标映射、右键粘贴和选中复制；切换设置分类时窗口尺寸保持固定。
- **跳板机**：在连接设置中展开“高级选项”，开启跳板机，分别填写目标服务器与跳板机的地址、端口、账号和认证信息。两端都支持密码、私钥或本机 SSH Agent；密码可分别选择本次记住或系统加密长期保存。终端、文件浏览、编辑与传输均通过跳板机，不会在跳转失败时改为直连。
- **跳板机复用**：可以从已有连接中复制跳板机设置；各目标保存配置快照，修改一个目标的跳板机不会改动其他目标。相同跳板机设置共享已记住的跳板机密码，清除时会提示影响范围。“复用跳板机连接”允许多个目标共用已建立的 SSH 连接，关闭一个目标不影响其他目标，最后一个目标断开后释放；关闭复用则各目标独立连接跳板机。跳板机和目标服务器分别验证指纹，不同跳转路径上的相同内网地址不会共用目标指纹。
- **新标签页**：标签栏的“＋”打开独立选择页，显示最近连接和快速连接入口，已保存服务器统一放在左侧。点击最近连接后在原标签内进入终端；取消或失败保留选择页。可同时保留多个选择页，前后标签快捷键也会切换这些页面。关闭最后一个标签会回到新的选择页，已有终端在切换时继续运行。
- **服务器条目**：展开侧栏时，每台服务器使用独立的圆角细边框，名称加重，账号和地址以次要文字显示，省去条目前置图标。收起侧栏后保留图标入口，分组图标继续用于区分分组。
- **主页与服务器**：主页显示最近 30 个成功连接，可关闭、清空或右键删除单条记录。左侧仅显示收藏，支持分组、折叠、顺序和六种图标；收起侧栏后仍保留分组名称、数量与折叠状态；右键分组标题可设置、排序或删除，不显示三点按钮。单击直接连接，已有多个同连接终端时优先保留当前标签；侧栏连接的“连接设置 → 高级选项 → 连接管理”可新建同名终端或删除连接。顶部终端标签右键仍可直接新开同名终端，切换与重连精确作用于所点标签。连接设置可单独保存，无需立即连接，收藏以勾选项为准，改名不会改变最近连接时间。
- **密码与重连**：登录密码、私钥口令和独立 sudo 密码可选择不记住、本次使用期间记住，或使用系统加密长期保存。“本次使用期间”在退出或重启应用后需重新输入；选择“长期记住 · 系统加密”可跨重启保存。密码按连接及账号身份隔离，改地址、账号或认证方式后不沿用旧密码。断线后在原标签提示重连，保留普通终端的滚动记录；可取消正在进行的连接。重连不会自动恢复编辑器回传、重试传输或执行旧命令。
- **sudo 密码快捷输入**：默认 `Ctrl+Alt+P` 将当前连接记住的密码填入终端，也可改绑；可以使用登录密码或设置独立 sudo 密码。默认不回车，设置中可选择自动回车。请在终端已提示 sudo 密码时使用；应用不会自动识别密码提示或自动提升权限。
- **命令管理**：右侧命令栏默认收起，按 `Ctrl+Shift+M` 展开。支持命名分组、搜索、排序、编辑和复制；分组可全局通用或属于某个连接，关闭标签、重连和应用重启后仍保留。可切换查看其他连接的命令，使用前显示来源、当前目标和完整内容。删除连接不会删除其专属命令。同一配置目录只运行一个程序实例，重复打开会回到原窗口，避免并行保存互相覆盖。
- **填入与运行**：命令可设置默认“填入终端”或“运行”，也可在发送时选择；填入不自动回车，运行追加回车。可要求运行前确认；借用其他连接命令始终预览确认。断线后禁止发送，不自动重试。多行或含 Tab 的命令要求当前终端程序启用括号粘贴模式，否则提示拒绝发送。
- **终端与文件**：多标签终端、可拖动高度的下方文件区；本地、远程可分别折叠，也可收起整个文件区让终端填满空间。目录、滚动位置与后台传输保留，选中文件仅高亮，不显示额外的已选数量栏；点击列表空白处取消选中。新建、删除等操作使用文件或空白处的右键菜单；跟随终端按钮放在远程路径栏旁，窄栏仅显示图标。
- **文件传输**：本地与远程目录同时浏览，系统文件选择器上传，双栏之间拖拽上传 / 下载，从 Windows 资源管理器拖入上传。支持目录递归、进度、取消和校验后续传。每个正在传输的任务显示实时速度及预计剩余传输时间；不计入续传已有字节，压缩任务按压缩包估算，不含打包、校验与解压时间。右键任务可强制停止或删除任务记录；删除进行中的任务会先停止传输，停止失败时保留记录，不删除本地或远程文件。传输队列可独立收起，只保留状态栏，后台任务继续。
- **打包压缩传输**：上传和下载前可选择普通传输或打包压缩；压缩模式把每个选中项分别打成 tar.gz，经过 SFTP 校验传输后自动解压到所选目录，保留名称、目录结构、常规权限和修改时间。队列显示压缩、传输、解压阶段，完成解压后才显示成功；取消或失败后清理临时文件，连接中断导致远程清理失败时提示临时目录位置。选择文件和传输方式期间切换标签，不改变原先的来源服务器和目标目录。
- **文件排序**：点击名称、大小、修改时间（远程另有权限）列切换升序／降序，当前列显示箭头。文件夹始终优先；名称按自然数字顺序、大小按真实字节、时间按实际时间排序，未知值靠后。本地与远程独立记住本次运行的排序，刷新、切换目录和折叠后保持。
- **文件操作**：本地与远程均提供新建文件、新建文件夹、重命名、复制路径和多选删除；工具栏、文件右键及空白处右键均有入口。新建不覆盖已有内容；删除前显示连接和完整路径，目录包含其中内容，属于永久删除。权限不足可按次 sudo 重试，已完成的删除项不会重复执行；切换标签或目录不改变已确认的目标。`.sh` 可普通运行、给所有者添加执行位后运行，或单次 sudo 运行。
- **跟随终端目录**：远程工具栏的“跟随终端”按标签独立开启，默认关闭；支持普通 Linux OpenSSH 终端及 tmux 的活动窗格。仅在文件区可见且当前标签开启时查询，手动浏览会暂停；隐藏文件区停止轮询。不修改 shell 配置，不向终端输入命令。需要远端 Python 3 和可读 `/proc`，无法确定当前目录、嵌套 SSH 或权限不足时明确暂停。
- **多行粘贴**：键盘粘贴、鼠标粘贴和系统粘贴共用选择框，可在框内编辑完整命令，回车只换行，清空后不能提交。整体粘贴和逐行粘贴都使用编辑后的内容；未编辑时保留原文。整体粘贴沿用终端的括号粘贴规则；逐行模式先填入当前行，由用户按回车提交，程序准备好后点击“填入下一行”。切换标签保留未提交的编辑，取消不发送；取消或 Ctrl+C 清除待处理队列，已填入的内容不自动删除；断线与重连不会继续旧队列。
- **内置文本编辑器**：本地与远程文件均支持行号、语法高亮、代码折叠、查找替换（含正则）、跳转行、撤销重做、多光标、缩进选择和 JSON 格式化。自动识别常见脚本与配置文件，也可手动选择语法模式。支持独立展开编辑器、自动换行、原始编码与换行保留；保存时检查原文件是否被修改，可并排查看最新版本。未保存时关闭会提示，断线保留编辑内容，可另存到本地。编辑器仅在打开文件时加载。
- **权限解释**：所有者、用户组、其他用户的读 / 写 / 执行复选框，显示八进制权限和含义。默认不递归，不增加 setuid / setgid。
- **按次 sudo**：普通操作遇到权限不足时，可选择输入 sudo 密码重试。密码不进入命令行、终端历史或配置；本次授权结束后不缓存。
- **外观与输入**：简约黑白主题、圆角控件与面板；顶部太阳 / 月亮按钮可快速切换，也可在“设置 → 字体与外观”中保存主题。在“设置 → 终端配色”可让终端跟随界面，或独立选择纯黑、柔和、白昼、石墨、经典、暖灰配色，并预览 ANSI 色卡。默认纯黑采用鲜明配色，原版浅色保留为“柔和”。终端输出默认不额外加粗，可在配色页开启；加粗不再自动提亮颜色，中英文字重选择继续生效。切换保留终端内容和背景图。DejaVu Sans Mono、JetBrains Mono、IBM Plex Mono 随包提供普通和真实粗体。中英文原生下拉列表分组突出可用的推荐字体，并列出本机安装字体；可选择字重、字号、行高、背景图、UTF-8 / GB18030 / Big5、无边框全屏与纯终端模式。顶部文件按钮默认仅显示图标，也可在通用设置中显示文字；窄窗口自动隐藏文字。
- **快捷键**：图形设置页直接捕获键盘按键，也可绑定鼠标中键、右键及侧键；显示冲突和普通单键对终端输入的影响。
- **防止误刷新**：移除框架默认的窗口刷新菜单与快捷键，`Ctrl+R`、`Ctrl+Shift+R` 等不会重置整个工作区。默认 `Ctrl+Shift+R` 仅在当前终端断线时重连；在线时继续由终端处理按键，`Ctrl+R` 历史搜索和 F5 等功能键保留。macOS 保留系统应用与文本编辑菜单。

默认键位：`Ctrl+Shift+R` 断线重连、`Ctrl+Alt+P` 填入 sudo 密码、`Ctrl+Shift+P` 快速连接、`Ctrl+Shift+F1` 设置、`Ctrl+Shift+[` 折叠 / 展开侧边栏、`Ctrl+Shift+]` 显示 / 隐藏终端标题及标签栏、`Ctrl+Shift+←/→` 切换前后终端标签、`Ctrl+Shift+E` 收起 / 展开文件区、`F11` 全屏、`Ctrl+Shift+F11` 纯终端、`Ctrl+Shift+C/V` 复制 / 粘贴。标题及标签栏默认显示，进入全屏或纯终端模式时保留其显示状态，也可随时使用快捷键隐藏、恢复。旧版连接与设置的默认键位自动迁移，已有自定义键位保留；旧绑定占用新增动作的默认键时，新动作保持未设置，可在设置页自行分配。显式鼠标绑定优先于“右键粘贴”偏好；文件列表右键保留文件菜单。

在 **设置 → 字体与外观** 中，英文字重与中文字重可分别选择，例如英文普通 400、中文粗体 700。下拉列表根据字体实际字形生成，过滤 Windows 模拟的粗体和斜体；某字体只有一种字重时会明确提示。更换字体会选择最接近的可用字重；旧版共用字重会同时迁移到中英文，保留原来的偏好。中文选项作用于 CJK 字符、全角字符和相应标点，英文字母、数字与终端线框保持独立。系统字体首次读取后复用缓存，新安装字体需重启应用。Windows 使用系统字体接口，macOS / Linux 读取系统 OpenType / TTC 字体，Linux 同时支持 Fontconfig 目录；新平台首次启动会选择可用的中文字体。当前字重列表读取静态字体字形，可变字体的完整连续轴尚未展开。

## 配置与备份

配置保存在当前用户的应用数据目录，独立于程序安装目录：Windows 为 `%APPDATA%\gooeshell`，macOS 为 `~/Library/Application Support/gooeshell`，Linux 为 `${XDG_CONFIG_HOME:-~/.config}/gooeshell`。

| 文件 | 内容 |
| --- | --- |
| `connections.json` | 服务器属性、跳板机设置快照、收藏、分组和最近连接 |
| `settings.json` | 主题、字体、快捷键等设置 |
| `known-hosts.json` | 保存的服务器指纹 |
| `host-key-preferences.json` | 各地址和端口的指纹验证偏好 |
| `credentials.encrypted.json` | 使用系统加密长期记住的目标／跳板机密码和私钥口令，两端独立保存 |
| `login-identities.json` | 共享登录身份名称、账号、版本及加密的长期密码；本次密码仅在内存中 |
| `keys/` | 在应用内新生成的密钥文件，每对密钥使用独立目录 |
| `command-library.json` | 命令与命令分组 |

部分文件在使用对应功能后才创建。应用不读取或修改 OpenSSH 的 `~/.ssh/config` 和 `~/.ssh/known_hosts`；选择已有私钥时保留原文件路径，连接配置只记录路径。升级或删除旧程序包不会清理上述数据。备份时先退出程序，复制整个应用数据目录，并另行保留外部私钥文件；加密密码依赖系统密钥，换电脑后可能需要重新输入。`--user-data-dir` 可用于显式指定独立配置目录。

## 当前边界

- **公钥推送**：需要 Linux/OpenSSH 服务器和 Python 3，作用于当前登录用户，不自动 sudo、不修改 SSH 服务配置或关闭密码登录。使用常规 `~/.ssh/authorized_keys`；服务器使用自定义授权来源或额外认证策略时，安装成功也可能无法独立密钥登录。拒绝链接及异常权限对象；失败或取消时已安装的公钥可能保留，会明确区分安装和验证结果。
- **sudo 文件能力**：支持目录浏览、文本读写、权限、重命名、新建文件／目录、删除与脚本运行；需要服务器有 Python 3 和 sudo，不安装或驻留远端服务。`requiretty` 策略不支持，明确报错。sudo 大文件传输尚未接入。
- **目录删除**：远程递归删除需要 Python 3，使用目录句柄检查，不沿符号链接递归；遇到挂载点、目录被替换或操作超限时停止并提示，已删除的内容无法恢复。普通文件删除和新建仍通过 SFTP。
- **校验与续传**：保留 `.gooeshell.part`，续传前检查全部已有内容，完成后检查完整文件。大文件优先在两端各自计算 SHA-256，只传回摘要，避免校验时再次下载整个文件；远端需支持 SSH 命令、Python 3，以及在校验目录创建临时路径验证文件。仅支持 SFTP、目录不可写或不兼容时自动使用并发回读校验，小文件直接回读。队列单独显示校验进度，校验不计入传输速度。不覆盖已有最终目标。下载发布需要本地文件系统支持硬链接；NTFS 可用。
- **压缩传输边界**：远程需要 Python 3，解压发布需要 Linux 的 `renameat2` 或 macOS 的 `renameatx_np` 支持；不支持仅提供 SFTP 的服务器。每个压缩任务失败或取消后重试会重新打包，不跨次续传；普通传输继续支持校验后续传。同名目标不覆盖，不合并目录；暂不处理符号链接、特殊文件、ACL 和扩展属性，每项最多 50000 个条目、64 层目录。双方需有可用临时空间；下载打包默认使用远端临时目录，源目录包含该临时目录时会明确停止。sudo 压缩传输尚未支持。
- **文本编辑**：支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE、GB18030、Big5，最大 2 MiB；大文件仅预览，二进制文件拒绝编辑。无 BOM 时先严格读取 UTF-8，其他编码需在“读取编码”选择；“保存编码”控制转换，无法表示的字符会阻止保存。保留原来的 LF/CRLF/CR 和混合换行，可手动统一换行。终端编码设置不改变文件编码。远程保存需要原子替换支持，保留常规权限、所有者和组；ACL、扩展属性尚未完整保留。只编辑普通文件，符号链接需打开实际目标。断线稿保留在当前窗口，可另存到本地；尚无崩溃后的自动草稿恢复、跨会话自动回传或外部编辑器联动。
- **脚本运行**：非交互执行，显示输出和退出码，最长约 60 秒、输出上限 2 MiB；交互式或长期任务请在终端运行。赋执行位成功但运行失败时，权限修改可能已生效。
- **加密与密码**：Windows 使用系统加密，macOS 使用系统钥匙串支持的加密，Linux 要求可用的 libsecret / KWallet；系统加密不可用时不降级为明文，可以选择仅本次记住。此方式不保护已登录系统中的恶意程序。丢失系统加密密钥后需清除旧密码并重新填写。
- **连接**：支持直连及单级普通 SSH 跳板机，跳板机需允许 TCP 转发；目标地址由跳板机侧连接。暂不支持多级跳转、登录后交互选择资产的堡垒机，也不读取 OpenSSH 配置别名、ProxyJump 或代理规则。不含本地 PowerShell / CMD 终端。
- **拖拽**：支持应用内双栏及 Explorer → 远程；远程文件直接拖出到外部 Explorer 尚未支持，可下载到本地栏选择的目录。
- **配色**：调整程序输出的 ANSI 颜色，不根据文字猜测文件类型；`ls` 需要服务器自身启用彩色输出，使用真彩色的程序可能采用自己的配色。本设置不修改远程 Shell 配置。
- **命令库**：保存在本机，命令正文不加密，请使用专用密码功能保存凭据。向当前交互程序发送输入，不检查终端是否正处于 Shell 提示符；使用前需确认当前程序。跨设备同步、变量模板和外部编辑器联动尚未实现。
- 命令历史仍使用远程 Shell 的 ↑ / ↓ / Ctrl+R，尚无跨服务器历史库或重启后自动恢复传输队列。
- 输入延迟仍需在实际服务器与网络下对比，不宣称公网零延迟或比 Xshell 更快。

tmux 已在本机真实 SSH、Linux PTY 环境验证启动、分屏、尺寸变化和连续输出。已修正原始字节转发、鼠标协议输入和重复窗口尺寸通知，启用低延迟 TCP 发送；用户报告的偶发画面停留尚未稳定复现，不将这些验证视为所有环境均已解决。测试详情见 [VALIDATION.md](VALIDATION.md)。

## 开发

需要 Node.js 22.12 或更新版本；安装依赖时会下载对应 Electron 运行组件：

```powershell
git clone https://github.com/gooesman/gooeshell.git
cd gooeshell/desktop
npm ci
npm run dev
```

`npm run build` 完整类型检查并构建；`npm test` 运行测试；`npm run pack` 在当前系统打包，输出到 `desktop/release/`。Windows 可运行 `npm run pack -- --win --x64`，macOS 使用 `--mac --arm64` 或 `--mac --x64`，Linux 使用 `--linux --x64`。各平台由对应系统的 GitHub Runner 原生构建，真实 SFTP 测试使用仅绑定 `127.0.0.1` 的临时服务器；Linux helper 在 Ubuntu 上实测。
