# 使用说明

## 连接与工作空间

快速连接统一提供 SSH 和本地终端。SSH 支持密码、私钥和 SSH Agent；共享登录身份当前支持用户名与密码。连接可以先保存再连接，收藏、分组、图标、编码、指纹、sudo、跳板机和公钥推送统一放在高级选项。

左侧仅显示收藏连接，单击直连；新标签页显示最近连接与快速连接入口。现有终端在切换标签时继续运行。连接设置中的高级连接管理可新开同名终端，终端标签右键也提供相应操作。最近连接可单独删除或关闭显示。

本地终端在 Windows 支持已安装的 PowerShell 7、Windows PowerShell 和 CMD；macOS / Linux 使用当前用户可用的系统 Shell。退出后保留画面，可通过重新打开或重连快捷键创建新进程，不自动恢复旧程序。

跳板机目前支持单级普通 SSH、TCP 转发、独立认证及可选连接复用。终端、文件与传输使用同一路线，失败时不会悄悄改为直连。暂不支持多级跳转、登录后交互选择资产的堡垒机或读取 OpenSSH 别名。

## 身份与指纹

在设置中预先保存登录身份，连接与跳板机分别选择。修改共享身份后，关联连接下次登录采用新信息；已有会话保留原登录用户。临时输入密码不会自动改写共享身份。密码保存位置和方式见[配置说明](CONFIGURATION.md)。

默认首次连接显示 SHA-256 指纹，可仅信任本次或保存。同一 IP 经常轮换设备时，可在连接高级选项按地址和端口设置自动接受指纹；这一方式无法识别冒用该地址的服务器，只适用于自己确认可信的环境。

公钥推送位于连接高级选项，可选择已有密钥或生成 Ed25519。仅安装公钥到目标登录用户的 `~/.ssh/authorized_keys`，不上传私钥；安装后用独立连接验证，成功才可将当前连接切换为私钥认证。需要远端 Linux/OpenSSH 和 Python 3，不自动 sudo 或修改 SSH 服务配置。

## 文件管理与传输

文件区位于终端下方，启动时收起；本地栏和传输队列也可单独折叠。目录和文件通过右键菜单新建、重命名、删除、修改权限或运行脚本。点击列标题排序，箭头表示方向；点击空白清除选择，不增加导致行位移的选中提示栏。

上传可通过本地文件选择器、双栏拖拽或 Explorer 拖入远程栏；下载使用所选本地目录。远程文件直接拖出到外部 Explorer 尚未支持。跟随终端目录可按标签开启，手动导航会暂停跟随。

普通传输保留 `.gooeshell.part`，续传前校验已有内容，完成后做完整校验；同名最终目标不覆盖。大文件优先在两端计算 SHA-256，只交换摘要；远端不兼容时退回有界并发回读。队列显示速度、预计剩余时间，校验进度单独计算，失败或进行中的任务可右键停止、删除。

打包压缩适合目录和大量小文件，传完后自动解压。需要远端 Python 3 及兼容的原子发布能力，双方需有临时空间；不支持压缩任务跨次续传、合并已有同名目录或 sudo 压缩传输。符号链接、特殊文件、ACL 和扩展属性暂不纳入压缩传输。

权限不足时可在应用内输入 sudo 密码完成支持的文件操作。此能力需要远端 Python 3 和兼容的 sudo 策略；`requiretty` 和 sudo 大文件传输尚不支持。递归删除会检查目录边界，不沿符号链接递归，已经完成的删除无法撤销。

## 文本编辑

内置编辑器提供语法高亮、行号、查找替换、撤销重做、跳转行、换行与编码选择，以及独立的深浅配色。支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE、GB18030 和 Big5，编辑上限 2 MiB；二进制文件拒绝编辑，大文件仅预览。保存前检查版本冲突，不默默覆盖远端变化。

无 BOM 时先严格读取 UTF-8；其他编码需要在读取编码中指定。保存编码控制转换，无法表示的字符会阻止保存。终端编码与文件编码独立。编辑普通文件，符号链接需打开实际目标；远程原子替换保留常规权限与所有者，ACL 和扩展属性尚未完整保留。

右键“用外部编辑器打开”下载本地草稿，默认使用系统关联，也可在设置中为 `.py`、`.md`、`.txt` 等分别指定程序。可能被系统直接执行的脚本类型需要显式指定文本编辑器。保存后自动回传，冲突时暂停并提供比较；断线或退出保留草稿，回到原连接后可恢复。

外部编辑支持不超过 2 MiB 的 UTF-8 / 带 BOM 的 UTF-16 普通文本，不自动下载 Markdown 相邻图片，也不自动提权。无法可靠判断外部编辑器的单个标签是否关闭，列表表示回传记录；已同步记录退出时不再提醒，未回传修改会显示完整文件位置。内置编辑器尚不提供崩溃后的草稿恢复，断线时可另存本地。

## 终端与命令

字体可分别设置中英文家族和实际可用字重，推荐字体以星号标记。终端配色映射 ANSI 调色板；`ls` 的文件类型着色需要服务器自身输出颜色，真彩色程序可使用自己的配色。设置不修改远程 Shell 配置。

多行粘贴先预览和编辑：Enter 整体粘贴，Ctrl+Enter 逐行粘贴，Shift+Enter 编辑换行。逐行模式中 Enter 执行当前行，Ctrl+Enter 填入下一行。普通 Shell 的 ↑ / ↓ / Ctrl+R 仍由 Shell 处理。

在连接高级选项开启 Bash 命令识别，下次连接启用。命令状态标记可放在左侧、右侧或隐藏，绿色表示退出码 0，红色表示非零退出；点击定位，右键复制命令或输出。Ctrl+↑/↓ 逐条跳转，在 tmux/Vim 备用屏幕内透传按键，暂不支持 tmux 面板级识别。当前集成读取 `~/.bashrc` 的交互非登录 Bash，不永久修改启动文件；不保证完整加载登录 profile。

右侧命令库默认折叠，可分组命名，作用域为全局或某个连接；重连保留连接专属命令，也可显式查看其他连接的分组。命令发送给当前交互程序，使用前需确认终端正在运行什么程序。命令正文不加密，不应代替密码存储。

## AI 接入

本机 MCP 复用连接、身份、跳板机和托管 sudo。短命令使用独立 SSH 通道，工作目录需要显式指定；后台任务可用 tmux，必须读取实际任务状态和退出码判断完成。接入、权限和边界见 [MCP 文档](MCP.md)。
