# 服务器之间传输文件

先在 GooeShell 连接源服务器和目标服务器。在**远程文件右键 → 传输到其他服务器…**中选择目标服务器及目录，点击子文件夹即可进入。开始后沿用文件区下方的传输队列，可查看路线、速度、剩余时间、校验进度，并通过右键停止或删除任务。

## 传输路线

- **自动**：尝试由源服务器通过 SSH 直推；连通、指纹或认证检测失败时，撤销本次临时授权，再尝试目标服务器反向拉取。
- **直推**：A 建立到 B 的 SSH 连接，把 A 的数据写入 B。
- **反向拉取**：B 建立到 A 的 SSH 连接，读取 A 的数据并写入 B。文件方向仍为 A → B。

文件数据由远端 `rsync` 经两台服务器之间的 SSH 连接传输。本机只发送控制消息，并接收状态和摘要。不会将文件下载到本机，也不会拼接两个本机 SFTP 流伪装成直传。两条路线都失败时停止；当前不提供本机中转或第三台服务器转发。

传输使用连接中保存的服务器地址与 SSH 端口，因此该地址还必须能从另一台服务器访问。跳板机能够让本机登录目标，并不代表两台目标服务器互通；此版不会自动复制本机的跳板链到远端。

## 首版支持范围

两端需要 Linux、Python 3、`rsync`、`rrsync`、OpenSSH 客户端工具（ssh、ssh-keygen、ssh-keyscan），并启用 SSH 公钥认证，且 SSH 服务读取当前用户的 `~/.ssh/authorized_keys`。Debian / Ubuntu 可先检查 `command -v rsync rrsync ssh ssh-keygen ssh-keyscan python3`；缺少工具时明确报错，不自动安装。保持系统 SSH 与 rsync 安全更新。

- 支持普通文件、目录树、空目录、中文和含空格的名称。保留内容、目录结构和修改时间；不承诺保留原所有者、ACL、扩展属性或硬链接关系。
- 暂不支持符号链接、管道、设备文件、sudo 传输或覆盖已有目标。包含保留名称 `.gooeshell-partial` 的源目录也会停止。
- 源目录不得包含同一服务器上的目标目录。文件在传输/校验期间发生变化时不会提交；这不是正在写入的数据库、整个系统或登录主目录的一致性快照方案。
- 多选项依次进入队列，避免多个大任务同时争用磁盘。开始前检查目录写权限与可用空间；其他进程仍可能在传输期间占用磁盘。

## 认证和临时授权

本机保存的登录密码和长期私钥不会复制到服务器。发起 SSH 的一端在随机的 0700 临时目录生成一次性 Ed25519 密钥；接收连接的一端暂时追加带 `restrict`、强制 `rrsync` 命令和过期时间的公钥。

直推时仅允许写入本次目标断点目录；反向拉取时仅允许读取所选项的父目录。临时密钥不允许交互 Shell、端口转发、Agent 转发或 PTY。直连 SSH 指纹必须匹配 GooeShell 当前已连接会话的指纹，不能用扫描结果自动信任陌生服务器。

结束、失败、取消及正常退出时清理临时授权与私钥，并保留原有 authorized_keys 条目。临时授权最长有效 24 小时，过期同时由 SSH 选项和强制命令检查。服务器掉电、网络强断或进程被强杀可能导致清理未完成，此时授权到期失效；可能残留带 `GooeShell-transfer-任务编号` 注释的过期行和仅当前用户可读的临时目录，需要管理员核对后清理。不会修改 sudoers 或全局 SSH 配置。

临时授权的增删使用文件锁并检查文件是否被替换，但无法强制其他不遵守相同锁的程序协调写入；正在传输时应避免同时通过其他工具修改同一用户的 `authorized_keys`。

## 断点与完整性

目标父目录中使用 `.gooeshell-transfer-摘要` 保存断点、元数据与锁。失败和取消不提交最终名称。重新选择同一源、目标目录和连接账号发起传输，可以复用远端断点；应用重启后的旧队列不保留，需要重新从文件右键发起。

新任务不做多余的 rsync 全量预校验；存在断点时使用内容校验修复不一致的已有数据。传输结束后，两端并行逐文件计算 **SHA-256**，同时比较完整目录清单与源文件变化记录。校验一致后才用 Linux `renameat2(RENAME_NOREPLACE)` 提交，目标被其他进程抢先创建时也不会覆盖。

源文件变化导致断点元数据不匹配时明确停止。可核对并手动移除错误提示中的断点目录后重新传输；不要在任务仍运行时删除该目录。

队列中的速度来自 rsync 当前报告的逻辑文件速度，剩余时间按尚待传输字节估算，不包含后续 SHA-256 扫描时间；续传、磁盘缓存和小文件会影响估计。校验阶段单独显示校验进度，不把“数据传完”当成“任务已完成”。
