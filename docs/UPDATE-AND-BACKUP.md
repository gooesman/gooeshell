# 更新与配置备份

在 **设置 → 更新与备份** 中检查 GooeShell 的 GitHub 正式版。选择适合当前系统的包后，程序将其下载到指定目录，按 GitHub 官方 Release 元数据核对大小和 SHA-256；校验失败或取消时不会生成最终文件。

Windows 便携版下载完成后可点击“安装并重启”。确认退出后，程序再次校验并准备更新包，经过已有的未保存文件检查，退出后替换程序目录并重启；旧目录保留在原位置旁的 `.gooeshell-previous-...` 中。若其他进程占用程序目录，更新可能失败，需要关闭占用进程后重试。macOS 和 Linux 可打开下载目录，按平台自行安装。

更新检查请求 GitHub 的官方 API，下载访问 GitHub 及其发布文件域名。下载速度受网络影响；网络错误不会被显示成“已是最新版本”。SHA-256 核对可以检测传输损坏和不匹配的文件，依赖通过 HTTPS 获取的官方 Release 元数据，不等于独立代码签名。macOS 当前分发包未经过 Apple 公证。

## 导出

输入至少 8 个字符的备份密码，选择是否包含长期保存的登录、跳板机和 sudo 密码及私钥口令，随后导出 `.gsbak` 文件。文件使用 scrypt 派生密钥和 AES-256-GCM 认证加密；备份密码用于换机恢复，不会保存到文件里。请选择独立、可靠的密码并妥善保存；丢失密码后无法恢复备份。

备份包含连接、连接分组、登录身份、命令库、界面设置及按地址的跳过指纹验证偏好。它不包含 SSH 私钥文件、仅本次使用的密码、已信任的主机指纹、最近连接记录、外部编辑草稿或 MCP 桥接令牌。私钥路径、背景图片路径和外部编辑器路径仅作为设置保存，换设备后可能需要重新选择文件。已信任的主机需要在新设备再次核对指纹。

## 导入

选择备份，输入备份密码并检查预览，再点击**合并导入**。原有连接及同标识的已有登录身份不会被覆盖；重复导入会跳过相同项目。导入的长期密码重新交给当前系统的加密存储；若系统密钥服务不可用，包含密码的备份不会开始导入。

导入界面设置和跳过指纹验证偏好是两个独立的可选项，默认均关闭。启用后，备份所列地址将不验证 SSH 主机身份。备份格式、密码和关联项目均在写入前验证；若后续磁盘写入或系统服务故障导致部分导入，界面会报告已添加的连接数量，不会声称全部成功。
