# 更新与配置备份

在 **设置 → 更新与备份** 中检查 GooeShell 的 GitHub 正式版。选择适合当前系统的包后，程序将其下载到指定目录，按 GitHub 官方 Release 元数据核对大小和 SHA-256；校验失败或取消时不会生成最终文件。

Windows 便携版下载完成后可点击“安装并重启”。确认退出后，程序再次校验并准备更新包，经过已有的未保存文件检查，退出后替换程序目录并重启；旧目录保留在原位置旁的 `.gooeshell-previous-...` 中。若其他进程占用程序目录，更新可能失败，需要关闭占用进程后重试。macOS 和 Linux 可打开下载目录，按平台自行安装。

更新检查请求 GitHub 的官方 API，下载访问 GitHub 及其发布文件域名。下载速度受网络影响；网络错误不会被显示成“已是最新版本”。SHA-256 核对可以检测传输损坏和不匹配的文件，依赖通过 HTTPS 获取的官方 Release 元数据，不等于独立代码签名。macOS 当前分发包未经过 Apple 公证。

## 导出

在 **设置 → 更新与备份 → 配置备份** 勾选范围。快捷键与鼠标、外观与通用设置、外部编辑器、命令库、登录身份、连接与分组均可独立选择。普通类别默认选中；只备份一种内容时，先点 **清空** 再勾选。展开 **选择分组和连接** 可以整组选，也可以只勾几台服务器；单选服务器会带上所属分组。展开 **选择身份** 可以逐个勾选。

当所选连接或跳板机使用了未选的共享身份时，点击 **带上关联身份** 可补选这些身份。也可以保留当前选择，导出时会保留 SSH 用户名，恢复后可重新绑定身份。命令库按整库导出。只恢复命令库时，连接专属命令尽量保留原归属；若缺少对应连接，可在命令分组中重新选择。

换电脑时，勾选 **包含所选连接和跳板机的 SSH 私钥文件**，私钥原文件会随连接进入加密备份。多条连接共用一把私钥时只保存一份。若私钥有口令并已长期保存，再勾选 **包含所选连接和身份长期保存的密码和私钥口令**。这两项均需主动勾选。「全选」只选择普通类别。SSH Agent 和硬件令牌由目标电脑配置。

没有口令的私钥会直接备份。如果 GooeShell 无法解密以前记住的密码，导出结果会列出对应连接。有口令的私钥可以在导出时补填原口令，程序会用私钥文件验证后把口令写入这份加密备份。也可以选 **保存备份，私钥口令以后再填**，等到连接服务器时再输入。

如果有其他已选密码无法备份，窗口会列出对应的连接或登录身份。点 **不带这些密码，保存备份** 会保存其余选中的内容。未勾选私钥文件时只保存路径。勾选后如果私钥文件本身打不开，需重新选择正确文件再导出。

**跳过指纹验证的地址** 默认关闭，按列出的完整地址清单独立选择。背景图片和外部编辑器仅保存路径。临时密码、已信任的主机指纹、最近连接、外部编辑草稿和 MCP 桥接令牌均不在备份中。

输入至少 8 个字符的备份密码并确认，导出加密的 `.gsbak` 文件。备份使用 scrypt 派生密钥和 AES-256-GCM 认证加密；丢失密码后无法恢复。新生成的范围备份需要用支持选择范围的版本打开。

## 导入

含 SSH 私钥文件的备份需要 1.5.9 或更高版本。迁移到新电脑时，在预览里勾选要恢复的连接、**恢复所选连接和跳板机的 SSH 私钥文件** 以及需要的已保存口令。程序将私钥恢复到当前用户的 GooeShell 私钥目录并更新连接路径。首次连接时可能需要确认服务器指纹，缺少私钥口令时需要输入原口令。旧备份只记录了路径，仍可导入。

选择备份文件并输入密码，点击 **验证并预览**。恢复时可再次选择类别、分组、连接和身份，也能从旧版整份备份中挑选。只想恢复快捷键时，点 **清空**，勾选 **快捷键与鼠标**，确认替换提示后点击 **合并导入**。

勾选的设置类别会替换本机对应设置；未选的设置及其未保存编辑继续保留。连接、分组、身份和命令按已有合并规则导入，不覆盖已有连接及其密码。导入默认不替换设置、恢复密码或启用跳过指纹验证。主动恢复长期密码时，系统加密存储必须可用；启用指纹偏好后，所列地址将跳过 SSH 主机身份验证。
