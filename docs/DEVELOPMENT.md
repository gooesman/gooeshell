# 开发基线与后续方向

这份文档合并终端原型、图形桌面版、外部编辑器和 MCP 连接桥接的已有决策。当前正式开发入口是 `desktop/`；产品延续 GooeShell 的连接和配置格式，不再推进早期 WezTerm / Rust 分支。

## 产品取舍

- Windows 优先，保留 macOS 与 Linux 的原生构建和验收。
- 输入延迟、终端连续输出和 tmux 兼容性优先。文件和网络操作不能阻塞界面线程；性能结论必须说明测试条件。
- 界面保持黑 / 白主题、扁平圆角和克制的色彩。文件区、本地栏、传输队列、命令库按需展开，减少重复入口；连接管理集中在连接设置和高级选项。
- 新标签页是工作起点，不直接新建 SSH。快速连接统一选择 SSH 或本地终端；已保存连接留在侧栏，主页显示可关闭的最近连接。
- 功能在展开 / 收起布局、键盘 / 鼠标、直接连接 / 重连之间保持一致；只修一条入口不算完成。

## 当前架构

| 位置 | 职责 |
| --- | --- |
| `desktop/src/main/main.ts` | 窗口、IPC、连接身份、设置和服务编排。 |
| `desktop/src/main/worker.ts`、`ssh-service.ts` | SSH / SFTP、跳板机、文件与传输任务。 |
| `desktop/src/main/local-pty-service.ts` | Windows ConPTY 与 macOS / Linux PTY。 |
| `desktop/src/main/external-editor*.ts` | 本地草稿、编辑器启动、自动回传、冲突和退出保护。 |
| `desktop/src/main/mcp-*.ts` | stdio 适配器、认证回环桥接与 AI 命令工具。 |
| `desktop/src/renderer/` | React 界面、xterm.js 终端与 CodeMirror 编辑器。 |
| `desktop/src/shared/` | 事件、数据结构、设置默认值与共用逻辑。 |
| `desktop/tests/` | 单元、回环 SSH、真实 Electron 和界面测试。 |
| `test-support/ssh/` | 桌面与移动原型共用的隔离 SSH / SFTP 夹具。 |

## 已合并的能力

- 本地终端、连接分组、共享登录身份、单级跳板机、独立指纹偏好、公钥推送与托管 sudo。
- 双栏文件管理、排序、权限和目录跟随；普通校验续传、压缩传输、速度 / 剩余时间和队列取消。
- 内置编辑器、编码与配色、按扩展名选择外部编辑器、保存后自动回传、冲突比较和草稿保留。
- 多行粘贴编辑及键盘流程、命令状态导航、分组命令库和统一快捷键设置。
- MCP / CLI 复用身份及连接；短命令、tmux 后台任务、日志和传输共用桥接，返回真实状态；桥接描述文件自检恢复。
- Linux 服务器间直推 / 反向拉取不经本机数据中转；任务专用 SSH 临时授权，断点续传、SHA-256 和不覆盖提交。

外部编辑器关闭标签并不等于结束回传记录。已同步记录退出时不提醒；尚未回传的修改列出服务器、文件路径和状态，保留进入列表处理的入口。共享登录身份更新后，关联连接下次登录采用新信息，已经连接的会话不更换用户。

## 后续方向

1. 持续处理用户实际复现的终端、文件传输和交互一致性问题，优先补齐回归证据。
2. 保持四平台 CI 和最终安装包验收有效，再发布稳定版；不能用 Windows 本地成功代替跨平台检查。
3. Android 使用独立、简化的移动端方案：先完成直接 SSH、多会话、密码 / 私钥认证和基础 SFTP。现有本地原型保留，尚不作为桌面正式发布的一部分。

不把路线图当作已完成功能。暂不承诺移动端与桌面配置同步、多级堡垒机、tmux 面板级命令识别、外部 Markdown 资源自动下载或 sudo 大文件传输。

## 开发完成标准

修改前说明范围和可验证目标；针对缺陷先复现。数据与凭据不得进入公开日志或截图。保留现有配置兼容性、未保存编辑保护和明确的取消语义。完成后检查源码、默认回归、相关真实界面或回环测试及最终成品；测试跳过与已知限制需明确记录。

2026-10-28 的仓库整理移除了未参与桌面构建的原型与上游源码。历史来源与恢复位置见 [历史说明](history/native-prototype.md)。
